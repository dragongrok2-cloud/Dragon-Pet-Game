# 🐉 Dragon Pet Game

Добро пожаловать в **Dragon Pet Game** — уютную игру, где ты выращиваешь и заботишься о своём собственном драконе!

## О проекте

Ты найдёшь маленького дракончика, будешь его кормить, играть с ним, обучать дыханию огнём и смотреть, как он растёт от милого детёныша до могучего крылатого друга.

### Возможности (план):
- Система ухода за питомцем (голод, счастье, энергия)
- Разные виды драконов
- Мини-игры и тренировки
- Эволюция и кастомизация
- Сохранение прогресса

## Как запустить

Пока проект в самом начале. Скоро здесь появится код!

```bash
# Клонировать репозиторий
git clone https://github.com/dragongrok2-cloud/Dragon-Pet-Game.git
cd Dragon-Pet-Game
```
